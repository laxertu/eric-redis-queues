Reference#

Redis support for eric-sse.

  • RedisStorage: a KvStorage, to persist channels, connections, listeners and queues;

  • RedisQueue: a durable Queue, whose messages live in a Redis list.

RedisQueue is described by a RedisConnection (host, port and database), so it can be pickled. RedisStorage takes a redis.Redis client. See eric_redis_queues.repository.redis_channel_repository_builder() to wire them together.

PREFIX_STORAGE = 'eric-redis-queues:kv:'#

Default key prefix of RedisStorage.

PREFIX_MESSAGES = 'eric-redis-queues:m'#

Key prefix of the lists holding RedisQueue messages.

PREFIX_WAKE = 'eric-redis-queues:wake'#

Prefix of the Pub/Sub channels notifying pushes to RedisQueue instances, one per database.

NOTIFIER_CLIENT_NAME = 'eric-redis-queues:notifier'#

Name of the Redis connections receiving push notifications, one per process and RedisConnection.

class RedisQueue#

Bases: Queue

Durable queue: messages are pickled and kept in a Redis list, so several processes can share it.

When pickled, e.g. by RedisQueueRepository, only its identity (connection data and queue id) is saved: its messages stay in Redis. Queues with equal connection data share one client.

pop() without timeout returns immediately, as eric-sse requires. With a timeout it waits for a message: this replaces BlockingRedisQueue of previous versions, callers choose whether to wait, e.g. with wait_next() or queue.pop(timeout=...).

Waits don’t poll and don’t hold a Redis connection: push() publishes a notification on a Pub/Sub channel, that one connection per process receives to wake the waiters of the queue. wait_pop() waits natively, without a thread. A waiter checks the queue once more when its timeout expires, so a lost notification can delay a message, never lose it.

Parameters:

  • redis_connection – Defaults to a local Redis, database 0.

  • queue_id – Identifies the Redis list. Defaults to a new uuid.

__init__(redis_connection=None, queue_id=None)#
Parameters:

  • queue_id (str | None)

async wait_pop(timeout)#

Waits for the next message without blocking the event loop.

The default implementation runs pop() with timeout in a worker thread, so it takes one thread per waiting call. Override it with a native async wait when possible.

Parameters:

timeout (float) – Seconds to wait for a message.

Return type:

Any

Raises a NoMessagesException if no message arrives within timeout.

class RedisQueueRepository#

Bases: KvQueueRepository[RedisQueue]

Creates, persists and loads RedisQueue instances.

Queues are stored as they are: only their identity (connection data and queue id) is serialised, their messages stay in Redis. Deleting a queue deletes its messages too, that would be left in Redis otherwise.

Parameters:

  • redis_connection – Connection of the queues it creates.

  • storage – Storage for queues identity, keyed by connection id.

redis_channel_repository_builder(channel_class, redis_connection=None, prefix=None)#

Returns a ChannelRepositoryBuilder persisting everything in Redis:

repository = redis_channel_repository_builder(SSEChannel, RedisConnection(host='localhost')).build()

It can be further configured before building, e.g. with listeners or error handlers.

Parameters:

  • channel_class (type[C]) – e.g. SSEChannel.

  • redis_connection (RedisConnection | None) – Used by queues, and by the storage of everything else. Defaults to a local Redis, database 0.

  • prefix (str | None) – Key prefix of the storage, see RedisStorage.

Return type:

ChannelRepositoryBuilder[C]
